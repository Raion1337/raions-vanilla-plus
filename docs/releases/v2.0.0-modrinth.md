# Raion's Vanilla Plus 2.0 — The Packwiz Rebuild

**Pure Minecraft, refined.**

Version **2.0.0** is a major rebuild of the modpack's technical foundation. Raion's Vanilla Plus is now managed through **Packwiz** rather than relying on a manually exported Prism Launcher instance.

## Highlights

- Rebuilt modpack distribution with versioned Packwiz metadata.
- Reorganized Fabric mods, shader packs, and resource packs into a reproducible `.mrpack` export.
- Included intended first-launch controls, resource-pack selection, and mod settings for Config Manager. Their in-game application still needs a clean-install test.
- Established a cleaner Git-based foundation for future updates and improvements.

## Before upgrading

**A fresh installation is recommended for 2.0.** Back up existing worlds and personal settings before replacing an older instance. Confirm that the selected release matches your Minecraft version.

This build targets **Minecraft 26.3**, **Fabric Loader 0.20.1**, and **Java 25**. Some included resource packs do not declare 26.3 support; their appearance needs in-game review.

> [!WARNING]
> Do not switch between different world-generation mod setups in an existing world without a backup. The planned Enhanced Worldgen edition includes Terralith and Tectonic; it is not part of this announcement unless explicitly listed as a separate release.

## Coming next

Graphics presets, more first-launch polish, separated world-generation editions, dedicated Fabric server packages, and automated release validation.
