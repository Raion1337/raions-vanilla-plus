# Raion's Vanilla Plus 2.0.1

This patch updates the mod selection, ships the current enabled resource packs in their saved order, and adds Pickup Notifier client defaults.

## Changes

- Added Crash Assistant, Dark Loading Screen, ShatterLib, Sound Physics Perfected, and spark.
- Removed LambDynamicLights because of performance issues when used with shaders. Since shaders are enabled by default, dynamic lighting is now optional: install LambDynamicLights manually if you want to use it.
- Replaced Sound Physics Remastered with Sound Physics Perfected.
- Updated CreativeCore to **2.14.22**, Simple Blood to **1.2.0**, Voxy Extra to **0.2.8**, XaeroPlus to **2.37.1**, Xaero's Minimap to **26.6.1**, and Xaero's World Map to **1.47.1**.
- Added Vanilla Experience+, Better Lanterns, Fresh Food, and Re-covered resource packs.
- Included Pickup Notifier client defaults through Config Manager.

## Installation and updating defaults

Import the `.mrpack` into your launcher for a fresh installation, or update your existing instance to 2.0.1.

To apply the latest modpack settings to an existing instance, open **Mod Menu → Config Manager** and select **Update**. This overwrites the settings supplied by the modpack with its current defaults, including the resource-pack selection and order. Settings the pack does not change retain your personal values.
