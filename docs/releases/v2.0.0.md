# Raion's Vanilla Plus 2.0 — The Packwiz Rebuild

> **Pure Minecraft, refined.**

Version **2.0.0** rebuilds the existing Fabric modpack as a Packwiz-managed release. The modpack was previously maintained through a Prism Launcher instance. Its vanilla-first selection remains focused on performance, visuals, and quality-of-life additions.

The goal stays the same: improve Minecraft's visuals, performance, and quality of life while preserving the familiar vanilla survival experience.

## What's New in 2.0

### Rebuilt modpack management

- Reorganized the modpack around Packwiz manifests and versioned metadata.
- Established a reproducible `.mrpack` export workflow.
- Added Git-based source and release documentation.

### Curated content

- Pinned 105 Fabric mod entries, 39 resource packs, and 6 shader packs through Modrinth download references.
- Packaged intended first-launch defaults for Xaero's Minimap, Simple Blood, Iris, keybindings, and resource-pack selection under `config/modpack_defaults/`.

### Better foundation for future updates

- Introduced a clearer separation between modpack files, developer tools, and release artifacts.
- Added archive integrity and SHA-256 checks for release builds.

## Installation

1. Download the **Raion's Vanilla Plus 2.0.0** `.mrpack` asset when this release is published.
2. Import it into **Prism Launcher** or the **Modrinth App**.
3. Let your launcher download the referenced content, then start Minecraft.

**Requirements:** Minecraft 26.3, Fabric Loader 0.20.1, Java 25.

> [!IMPORTANT]
> For this major rebuild, installing into a **new launcher instance** is recommended. Keep a backup of existing worlds and settings. Do not overwrite your old installation without first preserving its data.

## Compatibility and world safety

The included content is defined by this release's manifest. Back up worlds before upgrading Minecraft or changing mods. Existing-world safety has **not been tested**. Some pinned resource packs do not declare Minecraft 26.3 compatibility; review their visuals in game.

The planned **Vanilla Worldgen** and **Enhanced Worldgen (Terralith + Tectonic)** editions should not be assumed available until they have been separately published and tested. Do not remove Terralith from an existing world that was generated using it.

## Configuration compatibility

Config Manager is intended to copy defaults only when a destination file is missing. Launcher or mod initialization may create `options.txt` or another config file first. Archive inclusion is verified separately from application in Minecraft. **First-launch behavior is not tested** for this candidate. If minimap, Simple Blood, keybindings, shader selection, or resource-pack order differs from the intended defaults, include your launcher and pack version in a [GitHub issue](https://github.com/Raion1337/raions-vanilla-plus/issues).

The pack is client-focused. Some features need matching server-side mods; ordinary vanilla-server behavior and multiplayer have **not been tested** for this candidate. No dedicated server distribution is included.
